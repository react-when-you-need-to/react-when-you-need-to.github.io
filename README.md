An independent, single-file static project page for:

**React When You Need To: Event-Triggered Asynchronous Inference for VLA Policies**

The page includes only the paper title, authors from the supplied reference, and a coming-soon message. Upload `index.html` and `.nojekyll` to the root of a GitHub Pages repository when ready to publish.
