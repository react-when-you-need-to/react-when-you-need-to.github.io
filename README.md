# Paper project page

An independent, single-file static project page for:

**React When You Need To: Event-Triggered Asynchronous Inference for VLA Policies**

Open `index.html` in a browser to preview it. No installation or build is needed.

The review version contains an anonymous submission label and the abstract from the supplied paper, with the self-referential project-page sentence omitted. Author names, affiliations, contribution notes, and contact details are omitted from the HTML source. Restore author information only when preparing the public author version.

## Deployment

Upload `index.html` and `.nojekyll` to the root of a GitHub Pages repository, or serve the page from a research subdirectory such as `/research/real_time_chunking/` on a domain you control. Redirect the path without a trailing slash to the directory URL. The page is self-contained and supports either location without a build step. Use relative paths for future local images, videos, and documents.

No production domain is configured by this repository.
